# Grid Chomp

Минималистичный аркадный лабиринт в духе Vercel/Linear: тёмная тема, стеклянные панели,
типографика Geist, плавные микроанимации на Framer Motion. Никакого неона и пиксель-ретро.

Игрок убегает от полиции по **бесконечно генерируемому лабиринту** (чанки), собирает монеты,
покупает скины/звуки/музыку/бусты и выживает как можно дольше — один или в кооперативе.

## Стек

- **Next.js 14 (App Router)** + React 18
- **Supabase** — auth (Google/GitHub), база, RLS, Realtime (мультиплеер)
- **Tailwind CSS** + **Framer Motion** + **Geist** (шрифт Vercel)

## Что внутри

- **Бесконечный лабиринт** — детерминированная генерация чанками по seed; связность гарантируют
  «хребтовые» коридоры (шаг `SPINE`), между ними — шумовые блоки стен.
- **Камера на игроке**, строгое движение по сетке (как в Pac-Man).
- **ИИ полиции** — преследование через **A\***, динамический спавн за экраном (как в NFS/GTA),
  чтобы побег не был бесконечным.
- **Одиночная игра** — выживание на очки, монеты, растущая сложность.
- **Кооператив (2 игрока)** — host-авторитетный через Supabase Realtime: инстансные монеты,
  наблюдатель при гибели, возрождение через 7 секунд, командный рейтинг.
- **Экономика** — монеты → магазин (скины, звуковые наборы, музыкальные темы, бусты-расходники).
- **Процедурный звук** — Web Audio API (эффекты + фоновая музыка по музыкальным темам).

## Структура

```
app/                — страницы (welcome, dashboard, game, multiplayer, leaderboard, store, settings, credits, login)
components/
  ui.jsx            — примитивы (Button, GlassCard, Chip, Coin…)
  Header.jsx        — стеклянный хедер с навигацией
  Dpad.jsx          — экранный D-pad
  GameCanvas.jsx    — одиночная игра + HUD
  MultiplayerCanvas.jsx — кооператив + HUD
  panels/           — вкладки дашборда (Singleplayer, Multiplayer, Leaderboard, Profile, Settings, Store)
lib/
  catalog.js        — скины/звуки/музыка/бусты (цены)
  i18n.js           — RU/EN
  prefs.js          — настройки звука/музыки (localStorage)
  supabase/client.js
game/
  map.js            — бесконечный лабиринт (чанки)
  astar.js          — A*
  engine.js         — одиночный движок
  multiplayer.js    — кооператив
  sounds.js         — Web Audio (SFX + музыка)
supabase/schema.sql — таблицы, RLS, функции
```

## Быстрый старт

```bash
npm install
```

Создайте проект в [Supabase](https://supabase.com), выполните `supabase/schema.sql`,
заполните `.env.local` (см. `.env.local.example`) и настройте OAuth-провайдеры
(redirect — `<origin>/auth/callback`).

```bash
npm run dev
```

## Управление

- **Стрелки / WASD** — движение, **Esc / P** — пауза.
- На мобильных — экранный D-pad.

## Мультиплеер

Создайте комнату (вы — хост), поделитесь 6-значным кодом. Цель — выжить вдвоём как можно дольше.
Если игрок погибает — становится наблюдателем; если напарник продержится 7 секунд, погибший
возрождается. Командный результат попадает в рейтинг «Кооператив», а напарники автоматически
становятся друзьями.
